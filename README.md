# РЕЙД

Браузерная текстовая survival/extraction-игра в духе S.T.A.L.K.E.R. и Escape from Tarkov.
Выживайте в рейдах, собирайте лут, торгуйте, прокачивайте убежище и проходите сюжет.

Проект состоит из двух частей:

| Часть | Стек | Папка |
|---|---|---|
| Клиент | React 19 + Vite 8 | корень репозитория (`src/`, `public/`) |
| Сервер | ASP.NET Core 8 Web API (C#) | `GameApi/` |

## Быстрый старт

Двойной клик по **`start_game.bat`** — это тонкий ASCII-лаунчер, который вызывает
`scripts/start_game.ps1`: скрипт проверит зависимости, поднимет сервер, дождётся его
готовности, запустит клиент, дождётся Vite и откроет браузер.

Проверить окружение без запуска игры:

```powershell
start_game.bat -CheckOnly
```

Вручную (два терминала):

```powershell
# терминал 1 — сервер
dotnet run --project GameApi

# терминал 2 — клиент
npm install
npm run dev
```

Откройте <http://localhost:5173>.

Требования: .NET 8 SDK (или новее) и Node.js 18+ (проверено на Node 24).

## Как играть

1. **Меню** → «Продолжить» (если есть автосейв) или «Новая игра».
2. **Онбординг** — имя и аватар.
3. **Карта** — список локаций. Часть открывается за финальные задания торговцев,
   Градирни — по сюжету. В рейде: бои, тайники, сцены, ловушки и пустые клетки
   (на них тоже может попасться мелкий лут).
4. **Бой** — в стиле RPG Maker: выбор цели, атака, навыки (прицельный выстрел / очередь),
   предметы, защита и побег. Выносливость расходуется на действия, голод и жажда
   снижают урон, перевес мешает бежать.
5. **Выход из рейда** — прогресс синхронизируется, начисляется выживание и статистика,
   создаётся автосейв. Смерть обнуляет инвентарь и экипировку и идёт в статистику
   как проваленный рейд.
6. **Торговцы** — у каждого свой уровень лояльности: мощное оружие и снаряжение
   открываются по мере репутации. Покупка/продажа по категориям, бартер, задания.
   Скупщик покупает всё, но дёшево.
7. **Убежище** — пассивное восстановление каждые 5 секунд (HP, выносливость, еда/вода —
   в зависимости от модулей). Девять модулей: медблок, зона отдыха, кухня, водоочистка,
   схрон, мастерская, генератор, оружейная, спортзал. Максимальный уровень — 5.
8. **Сюжет** — 10 глав по 10 заданий (100 всего): от бункера после погони до финала
   в Градирнях. После финала доступна свободная игра (Freeplay).
9. **Навыки** — за каждый уровень даётся очко, которое вкладывается в перки
   (урон, защита, HP, выносливость, лут, торговля, регенерация, медицина).
10. **Настройки** — 4 темы интерфейса (Сталкер, Метро, Тарков, Фоллаут),
    громкость музыки/эмбиента/звуков и сброс прогресса.
11. **Кассеты** — находятся в рейдах; в убежище есть встроенный проигрыватель.
    Музыка меню играет только в меню, эмбиент — только в игре.

Опыт даёт уровни (до 50): каждый уровень +10 к максимуму HP и +5 к выносливости,
плюс очко навыка. Враги автоматически усиливаются вместе с уровнем игрока.

## Возможности

- 7 локаций: 6 открываются цепочками торговцев, Градирни — сюжетом;
- 65 предметов: оружие (включая AEK 971 «Прототип», QJY-88, Barrett M82, Glock 17),
  броня, рюкзаки, еда, медицина, материалы, кассеты, ценный лут;
- градация лута по тирам локаций — на первой локации не выпадет «имба»;
- 5 торговцев: цепочки заданий (20), ежедневные задания (15), лояльность и бартер;
- сюжет: 10 глав / 100 заданий с финалом и свободной игрой;
- вес предметов, выносливость, голод и жажда влияют на рейд и бой;
- инвентарь в стиле S.T.A.L.K.E.R.: сетка, вес, экипировка, описание по клику;
- убежище с 9 модулями, пассивным регеном и схроном;
- 9 навыков, уровни и опыт, статистика выжившего;
- музыка: отдельная тема меню, эмбиент в игре, кассетный проигрыватель в убежище,
  звуки наведения/клика и завершения задания; громкость регулируется в настройках;
- сохранения в JSON: слоты 1–9 + автосейв (каждые 30 секунд и после рейда),
  включая прогресс заданий; удаление сохранений из меню и вкладки «Сохранения».

## Структура

```
raid-game-client/
├─ index.html              # HTML-оболочка
├─ vite.config.js          # dev-сервер 5173 + прокси /api → localhost:5000
├─ start_game.bat          # ASCII-лаунчер (двойной клик)
├─ scripts/start_game.ps1  # проверка окружения, запуск сервера и клиента
├─ public/                 # аватары, враги, предметы, локации, торговцы
├─ src/
│  ├─ api.js               # все запросы к серверу
│  ├─ App.jsx              # меню, вкладки, рейд, тосты, автосейв
│  ├─ App.css              # вся вёрстка
│  └─ components/          # UI: инвентарь, торговцы, убежище, квесты, рейд…
└─ GameApi/
   ├─ Program.cs           # CORS, сервисы, статика, загрузка автосейва
   ├─ Controlles/          # GameController, RaidController, SaveController
   ├─ Models/              # Player, Item, Enemy, Quest, Location…
   ├─ Services/            # каталоги, лут, квесты, прогрессия, состояние
   ├─ Properties/          # launchSettings (порт 5000)
   └─ saves/               # JSON-сохранения (не коммитятся)
```

## API

Все маршруты начинаются с `/api`.

| Группа | Маршруты |
|---|---|
| Игрок | `GET /player`, `POST /player/sync`, `POST /player/die`, `POST /player/onboard`, `POST /player/avatar`, `POST /dev/reset` |
| Инвентарь | `POST /equip/{id}`, `POST /unequip/{slot}`, `POST /consume/{id}`, `POST /sell/{id}`, `POST /sell-partial`, `POST /inventory/drop/{id}`, `POST /inventory/add` |
| Торговцы | `GET /traders`, `POST /traders/{id}/buy-batch`, `POST /traders/{id}/barter/{offerId}` |
| Убежище | `GET /shelter/info`, `GET /shelter/regen-info`, `POST /shelter/upgrade/{module}`, `POST /stash/store/{id}`, `POST /stash/take/{id}` |
| Навыки | `GET /perks`, `POST /perks/{id}` |
| Задания | `GET /quests`, `GET /quests/trader/{id}`, `GET /story`, `POST /quests/{id}/accept`, `POST /quests/progress`, `POST /quests/{id}/complete` |
| Рейд | `GET /raid/locations`, `POST /raid/start`, `POST /raid/combat/start`, `POST /raid/combat/action` |
| Сейвы | `GET /saves/list`, `POST /saves/save/{slot}`, `POST /saves/load/{file}`, `DELETE /saves/delete/{file}` |
| Прочее | `GET /api/health` |

## Настройка

- **Порт сервера** — `GameApi/Properties/launchSettings.json` (по умолчанию 5000).
- **Прокси клиента** — `vite.config.js` (`/api` → `http://localhost:5000`).
- **Отдельный адрес API** — переменная окружения `VITE_API_URL` (см. `.env.example`),
  нужна для десктопной сборки, где клиент открывается не с dev-сервера.
- **CORS** разрешает только `localhost`/`127.0.0.1` — игра локальная.

## Сборка

```powershell
npm run lint         # ESLint
npm run build        # статика клиента в dist/
npm run build:api    # статика клиента в GameApi/wwwroot (раздаётся тем же сервером)
dotnet publish GameApi -c Release
```

После `npm run build:api` сервер отдаёт интерфейс с <http://localhost:5000> —
это удобная основа для упаковки в Electron/Tauri.

## Ограничения и планы

- Игра рассчитана на одного игрока; состояние живёт в памяти сервера и пишется в JSON.
- Десктопная оболочка (Electron/Tauri) пока не добавлена — см. раздел «Сборка».
- Тестов нет; проверка — сборка + ручной прогон.

## Если что-то не работает

- **Порт занят** — `netstat -ano | findstr :5000` (или :5173), закройте процесс
  либо поменяйте порт в `launchSettings.json` и `vite.config.js`.
- **«Сервер недоступен»** — смотрите окно «Game API Server»; часто это отсутствующий
  .NET 8 Runtime.
- **Сброс прогресса** — «Настройки» → «Сбросить всё» либо удалите файлы в `GameApi/saves/`.
