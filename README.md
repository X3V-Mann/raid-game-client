# РЕЙД

Браузерная текстовая survival/extraction-игра в духе S.T.A.L.K.E.R. и Escape from Tarkov.
Выживайте в рейдах, собирайте лут, торгуйте, выполняйте задания, прокачивайте убежище и проходите сюжет.

Проект состоит из двух частей:

| Часть | Стек | Папка |
|---|---|---|
| Клиент | React 19 + Vite 8 | корень репозитория (`src/`, `public/`) |
| Сервер | ASP.NET Core 8 Web API (C#) | `GameApi/` |

## Быстрый старт

### Windows (лаунчер)
Двойной клик по **`start_game.bat`** — он вызывает `scripts/start_game.ps1`: проверяет зависимости, поднимает сервер, ждёт готовности, запускает клиент и открывает браузер.

Проверка окружения без запуска:
```powershell
start_game.bat -CheckOnly
```

### Вручную (два терминала)
```powershell
# терминал 1 — сервер
dotnet run --project GameApi --urls http://localhost:5000

# терминал 2 — клиент
npm install
npm run dev
```

Откройте <http://localhost:5173>.

**Требования:** .NET 8 SDK и Node.js 18+.

## Как играть

1. **Меню** → «Продолжить» (если есть сохранение/автосейв) или «Новая игра».
2. **Онбординг** — имя и аватар.
3. **Карта** — выбор локации и рейд: бои, лут/тайники, сцены и события. Доступность локаций открывается по прогрессу (задания/сюжет).
4. **Бой** — пошаговый: атака, навыки, предметы, защита, побег. На исход влияют характеристики, снаряжение, голод/жажда и выносливость.
5. **Выход/смерть** — успешный выход синхронизирует прогресс и статистику; смерть ведёт к потере инвентаря/экипировки (по правилам игры) и отражается в статистике.
6. **Торговцы** — покупка/продажа, бартер, репутация/лояльность, ассортимент и цепочки заданий. Во вкладке «Торговцы» играет отдельная музыка (эмбиент в это время не накладывается). Предметы, полученные по бартеру, считаются найденными в рейде («из рейда»).
7. **Доска объявлений** — побочные/срочные задания. Показываются задания по доступным локациям и от доступных торговцев; указан заказчик (репутация начисляется при сдаче).
8. **Дневник** — сюжетные задания открываются последовательно (сначала текущее, следующее появляется после выполнения), есть вкладка **«Выполненные»**. Также: **мысли ГГ** (автоматические записи) и отдельная вкладка **«Заметки»** игрока.
9. **Убежище** — модули/улучшения, пассивное восстановление, схрон, крафт/утилиты по мере прогресса.
10. **Навыки/перки, статистика, сохранения, настройки** — прокачка, профиль выжившего, слоты сохранений/автосейв, темы и звук.

## Основные возможности

- Рейды по локациям с боями, лутом и событиями.
- Торговцы: лояльность, категории торговли, бартер, цепочки заданий в диалоге (открываются по порядку).
- Сюжет с последовательным открытием заданий и финалом/свободной игрой (по прогрессу).
- Доска объявлений: побочные задания, срочные задания с лимитом игрового времени, фильтр по доступным локациям/торговцам.
- Инвентарь, экипировка, схрон, убежище и крафт/улучшения.
- Навыки/перки, уровни, игровая статистика.
- Дневник: сюжет, выполненные задания, мысли ГГ и заметки игрока.
- Аудио: меню/эмбиент, музыка во вкладке торговцев, звуки интерфейса, кассеты/настройки громкости.
- Сохранения в JSON (слоты + автосейв), загрузка/удаление.

## Структура

```text
raid-game-client/
├─ index.html
├─ vite.config.js              # dev-сервер 5173 + прокси /api → localhost:5000
├─ start_game.bat / scripts/   # запуск окружения (Windows)
├─ public/                     # ассеты (аватары, враги, предметы, локации, аудио и т.д.)
├─ src/
│  ├─ api.js                   # запросы к серверу
│  ├─ audio.js                 # музыка/эмбиент/звук
│  ├─ App.jsx                  # состояние UI, вкладки, рейд
│  └─ components/              # интерфейс (карта, торговцы, дневник, рейд, убежище…)
└─ GameApi/
   ├─ Program.cs               # конфигурация, статика wwwroot, загрузка автосейва
   ├─ Controlles/              # API-контроллеры (игра, рейд, сохранения)
   ├─ Models/                  # модели (игрок, предметы, квесты, локации…)
   ├─ Services/                # каталоги, лут, квесты, прогрессия, состояние
   ├─ Properties/              # launchSettings (порт 5000)
   └─ saves/                   # JSON-сохранения (в .gitignore)
```

## API

Все маршруты начинаются с `/api` (основные группы):

| Группа | Примеры маршрутов |
|---|---|
| Игрок | `GET /player`, `POST /player/sync`, `POST /player/die`, `POST /player/onboard`, `POST /player/avatar`, `POST /dev/reset` |
| Инвентарь | `POST /equip/{id}`, `POST /unequip/{slot}`, `POST /consume/{id}`, `POST /sell/{id}`, `POST /sell-partial`, `POST /inventory/drop/{id}` |
| Торговцы | `GET /traders`, `POST /traders/{id}/buy-batch`, `POST /traders/{id}/barter/{offerId}`, `GET /traders/{id}/dialogue`, `POST /traders/{id}/talk` |
| Убежище/схрон | `GET /shelter/info`, `POST /shelter/upgrade/{module}`, `POST /stash/store/{id}`, `POST /stash/take/{id}`, `POST /craft/{recipeId}` |
| Навыки | `GET /perks`, `POST /perks/{id}` |
| Задания/сюжет | `GET /quests`, `GET /quests/trader/{id}`, `GET /story`, `GET /quests/board`, `POST /quests/{id}/accept`, `POST /quests/{id}/complete`, `POST /story/ending-choice` |
| Дневник/время | `GET /diary`, `POST /diary/note`, `GET /gametime`, `POST /gametime/advance` |
| Рейд | `GET /raid/locations`, `GET /raid/state`, `POST /raid/start`, `POST /raid/step`, `POST /raid/combat/start`, `POST /raid/combat/action` (и др.) |
| Сохранения | `GET /saves/list`, `POST /saves/save/{slot}`, `POST /saves/load/{file}`, `DELETE /saves/delete/{file}`, `POST /saves/autosave` |
| Прочее | `GET /api/health` |

> Точный набор маршрутов см. в `GameApi/Controlles/*Controller.cs`.

## Настройка

- **Порт сервера** — `GameApi/Properties/launchSettings.json` и параметр `--urls` (по умолчанию `http://localhost:5000`).
- **Прокси клиента** — `vite.config.js` (`/api` → `http://localhost:5000`).
- **Отдельный адрес API** — переменная `VITE_API_URL` (`.env.example`), если клиент открывается не с dev-сервера.
- **Папка сохранений (опционально)** — переменная окружения `RAID_SAVE_DIR` переопределяет директорию сохранений `GameApi` (полезно для оболочек/упаковки).

## Сборка

```powershell
npm run lint         # ESLint
npm run build        # клиент в dist/
npm run build:api    # клиент в GameApi/wwwroot (сервер отдаёт UI с http://localhost:5000)
dotnet publish GameApi -c Release
```

После `npm run build:api` интерфейс можно открывать с `http://localhost:5000` (удобно для дальнейшей упаковки в десктоп-оболочку).

## Ограничения

- Одиночная игра: состояние в памяти сервера, сохранения — в JSON.
- Готовой десктопной оболочки (Electron/Tauri) в репозитории сейчас нет; есть основа для упаковки (`build:api`, `RAID_SAVE_DIR`).
- Автотестов нет; проверка — сборка и ручной прогон.

## Если что-то не работает

- **Порт занят** — `netstat -ano | findstr :5000` (или `:5173`), освободите порт или поменяйте в `launchSettings.json`/`--urls` и `vite.config.js`.
- **«Сервер недоступен»** — проверьте, что `GameApi` запущен на `http://localhost:5000` и Vite проксирует `/api`.
- **Старое поведение после обновления** — перезапустите `GameApi` (старый процесс отдаёт старый код).
- **Сброс прогресса** — через настройки/сброс в игре или удалите JSON-файлы в `GameApi/saves/`.
